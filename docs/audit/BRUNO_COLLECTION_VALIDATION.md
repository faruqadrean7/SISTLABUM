## 3. Environment & Security Hygiene Findings

1. **Zero Secret Leakage:** Neither `environments/Local.bru` nor `environments/Testing.bru` contain live production secrets, real database credentials, or real student PII. Tokens are templated as placeholders (`{{adminToken}}`, `{{studentToken}}`, etc.).
2. **Base URL Parameterization:** All requests strictly consume `{{baseUrl}}` variable, avoiding hardcoded IP addresses or external hostnames.
3. **Execution Workaround:** Since the `bru` CLI is not installed on the system, automated validation was executed using a dedicated AST parser. Developers with the Bruno desktop app can immediately open `docs/api/bruno/SISTLABUM/` and run the collection against `http://127.0.0.1:8000/api/v1`.
